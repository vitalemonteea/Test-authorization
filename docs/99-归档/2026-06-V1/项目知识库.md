## 二、技术栈

| 维度 | 内容 |
|------|------|
| **前端框架** | Layui |
| **设计系统** | Material Design 3（MD3） |
| **图标库** | Material Symbols Outlined |
| **渲染方式** | 产品线驱动的前端动态渲染——监听左侧产品线下拉框选择事件，动态更新右侧模块导航的 DOM 结构 |

### MD3 设计系统关键值

- 背景色（surface 容器色）：`#f8f9ff`
- 卡片背景色：纯白 `#fff`
- 主色（primary）：`#0050cb`
- 卡片圆角：`12px`
- 输入框/按钮圆角：`8px`
- 卡片无边线，依赖双层阴影 + hover 效果增强立体感
- 所有 UI 组件严格遵循 MD3 色彩与间距体系
- 配色完整定义在 `tailwind.config.colors` 中

## 三、V2 架构设计

### 3.1 双字段正交架构（2026-06 确认）

| 字段 | 说明 | 选项 |
|------|------|------|
| **authScene**（授权场景） | 控制 CM 字段显隐、硬件文件隐藏、商务类拦截等 | 5 个选项，分 3 大类（见下） |
| **planDevType**（申请类型） | 决定 SN 及借测字段显隐 | 2 个选项 |

**关键原则**：硬件/软件不作为场景维度，完全由 `planDevType` 字段承载。两字段固定顺序：`authScene` → `planDevType`。

### 3.2 三大申请场景

| 场景 | value | 说明 |
|------|-------|------|
| **开通测试授权** | 1 | 无授权或授权过期的首次申请，内部通过设备类型字段（硬件/软件）区分 |
| **授权资源调整** | 2 | 授权有效期内的延长/增开/扩容操作 |
| **商务类申请** | 3/5/6 | 销售设备增开新模块、销售授权扩容、销售设备延长授权 |

## 八、常见陷阱记录

- PowerShell 压缩 API 不支持中文路径（需用 Compress-Archive 兼容方案）
- CSS flex 居中被高权重父样式覆盖
- CSS 样式覆盖需提升选择器特异性
- JS 显隐控制与 CSS display 冲突
- DOM 元素重复 click 监听器导致状态冲突
- 文件校验硬编码为 false 导致始终失败
- 工作环境未安装 Git 导致命令失败

## 九、重要设计决策记录

完整列表参见原记忆目录，关键决策包括：

- 模块组织采用扁平化平铺结构
