# 测试设备授权平台 V2 需求概述

> 更新时间：2026-07-28  
> 适用页面：`测试设备授权平台V2.html`  
> 整理口径：以当前 V2 原型页面为准，按照页面从上到下、从左到右的视觉顺序梳理“页面、模块、功能点”。

## 1. 页面需求概述

| 页面 | 模块 | 功能点 | 版本 |
| --- | --- | --- | --- |
| 申请产品授权 | 基本信息 - 产品与版本 | 1. 选择产品线并按在售、已退市分区展示，其中已退市产品仍可申请，但需展示风险提示。2. 切换产品线时清理上一产品产生的设备、场景和授权配置状态。3.支持搜索产品线   | V2 |
| 申请产品授权 | 基本信息 - 客户与组织 | 1. 搜索并选择客户，展示客户类型和销售负责人。 2. 客户编码仅用于内部查询，不在页面显示。 3. 根据客户类型调整授权日期上限，普通客户默认最长 90 天，KA 客户最长 180 天。 4. 选择区域、办事处并填写授权接收邮箱。 | V2 |
| 申请产品授权 | 基本信息 - 授权对象录入 | 1. 普通产品支持选择申请类型，并按场景录入设备 ID、设备 SN。 2. 设备 ID、设备 SN 支持多值录入、单项删除及重复值控制。 3. 硬件借测场景根据设备反查借测单，并可自动带出同借测单设备。 4. HCI、SCP 不展示设备 ID，改为上传硬件信息文件识别集群授权信息。 5. 纯软测试只查询授权历史，不校验客户自有设备资产有效性。 | V2 |
| 申请产品授权 | 设备识别与授权场景 | 1. 根据设备来源、授权状态和授权历史识别首次开通、重新开通或调整当前测试授权等可申请场景。 2. 有效授权可申请延期、增开模块或扩大容量/规格。 3. 销售设备仅开放适用的商务类授权事项。 4. 展示来源、授权中台、累计测试、历史申请和最新授权有效期等识别结果。 | V2 |
| 申请产品授权 | 超期与特殊申请补充 | 1. 区分授权已过期与累计测试超期，两类状态可同时出现。 2. 超期申请提示升级审批及区域经营成本影响。 3. 超期申请要求填写申请理由，并支持上传证明材料。 4. 特殊规则、不可自助或设备不一致时阻断提交并说明原因。 | V2 |
| 申请产品授权 | 多设备兼容与拆单 | 1. 校验多设备的产品线、基础场景、申请事项、来源、借测单、材料和审批规则是否一致。 2. 同借测单设备允许自动补齐并由用户删除不参与本次申请的设备。 3. 多设备条件不兼容时明确指出冲突设备和原因，并要求拆分申请。 | V2 |
| 申请产品授权 | 授权配置 | 1. 以模块卡片展示当前产品线可配置的授权模块。 2. 已授权模块默认开启，并展示“已授权”状态及授权有效期。 3. 支持模块启用/停用、展开/折叠、全部展开/全部折叠。 4. 支持填写模块参数、容量和授权日期。 5. 支持将统一授权日期应用到所有已启用模块。 6. 已禁用模块不参与校验和提交。 | V2 |
| 申请产品授权 | 右侧模块导航 | 1. 桌面端展示当前产品线对应的模块列表。 2. 点击导航项定位到对应模块卡片。 3. 页面滚动时同步更新当前模块高亮状态。 4. 产品线切换时刷新导航内容。 | V2 |
| 申请产品授权 | 底部操作区 | 1. 实时提示当前提交前置条件，如识别设备、选择申请内容或补齐信息。 2. “重置”清空表单和派生状态，并恢复默认产品模式。 3. “立即获取”执行校验、组装设备事实和规则快照后提交申请。 4. 查询失败时支持重试或保存草稿。 | V2 |
| 授权记录 | 页面标题与状态概览 | 1. 展示授权记录页面说明。 2. 按全部、待审批、审批中、已通过、已授权、已驳回、已过期汇总记录数量。 3. 点击状态项直接筛选列表，并与状态筛选条件同步。 | V2 |
| 授权记录 | 查询条件 | 1. 按授权类型、审批状态、产品线、设备 ID/SN、申请人、申请日期筛选。 2. 支持查询和重置。 3. 查询条件与状态概览保持同步。 | V2 |
| 授权记录 | 授权记录列表 | 1. 展示申请编号、授权类型、申请平台、产品线/方案、版本、客户、授权对象、区域、有效期、申请人、申请时间、审批状态和操作。 2. 固定关键列和“审批状态/操作”列，横向滚动时保持可读。 3. 解决方案记录支持展开查看子设备授权明细。 4. 支持分页、每页条数切换和页码跳转。 | V2 |
| 授权记录 | 记录操作 | 1. 根据记录状态展示查看、审核、下载、复制、续期、重新提交、撤销等操作。 2. 复制产品授权或 XaaS 记录后跳转对应申请页并回填可复用信息。 3. 已授权、已过期记录允许下载本次生成的授权文件。 4. 已过期或需延期记录可发起续期申请。 5. 已驳回记录可补充信息后重新提交。 | V2 |
| 授权记录 | 详情侧边抽屉 | 1. 保留列表上下文，在右侧展示记录详情。 2. 产品授权详情依次展示申请信息、客户信息、产品授权明细、业务补充信息、开通结果和审批信息。 3. XaaS 详情依次展示申请信息、客户信息、订阅授权明细、业务补充信息、开通结果和审批信息。 4. 不同授权类型保持统一宽度、标题、只读表单和分区样式。 | V2 |
| 授权记录 | 审核申请侧边抽屉 | 1. 按详情页相同信息骨架向审批人展示申请依据。 2. 展示已有审批记录和当前审批节点。 3. 审批人必须主动选择通过或驳回，并填写审批意见。 4. 审批操作完成后更新当前记录状态；原型仅演示页面交互，不定义真实审批流。 | V2 |
| 授权记录 | 撤销与结果反馈 | 1. 撤销申请使用二次确认弹窗，并要求填写撤销原因。 2. 下载、复制、续期、重新提交和审核操作提供结果提示。 3. 操作入口支持悬浮说明和键盘访问。 | V2 |
| 授权记录 | 导出 | 1. 提供授权记录列表导出入口。 2. 导出内容受当前查询条件约束。 | V2 |
| 移动端 | 页面适配 | 1. 不展示桌面端导航栏和产品授权右侧模块导航。 2. 产品授权与 XaaS 授权表单采用单列展示，并保留底部操作区。 3. 授权记录提供设备 ID/SN 搜索以及类型、状态、产品线快捷筛选。 4. 支持展开更多筛选条件和一键重置，并与状态概览保持同步。 | V2 |

## 2. 范围说明

1. 本文档为需求概述，用于说明页面功能和边界，不替代字段级、规则级详细需求文档。
2. 当前原型中的审批规则计算用于演示申请分流和页面展示；真实审批流、授权开通和外部系统接口需由对应系统另行定义。
3. 页面中隐藏的旧版查询区、仅保留在代码中的遗留交互和异常处理演示不纳入本概述。
