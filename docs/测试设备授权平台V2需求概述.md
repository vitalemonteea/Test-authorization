# 测试设备授权平台 V2 需求概述

> 更新时间：2026-07-28  
> 适用页面：`测试设备授权平台V2.html`  
> 整理口径：以当前 V2 原型页面为准，按照页面从上到下、从左到右的视觉顺序梳理“页面、模块、功能点”；截图中明确标注的 V3 内容单独列为规划项。

## 1. 页面信息架构

1. 全局顶部区域：移动端菜单入口、操作手册、系统设置、登录用户信息。
2. 全局左侧区域：后台首页、申请产品授权、申请 XaaS 授权、授权记录、授权申请接口人入口。
3. 工作区顶部：已打开业务页面的页签入口。
4. 工作区主体：根据当前页签展示产品授权申请、XaaS 授权申请或授权记录。
5. 工作区右侧：仅桌面端产品授权页面展示模块导航；移动端不展示。
6. 页面浮层：根据用户操作展示详情抽屉、审核抽屉、续期/重新提交抽屉、撤销确认弹窗及结果提示。

| 页面 | 模块 | 功能点 | 版本 |

| 全局框架 | 左侧主导航 | 1. 展示后台首页、申请产品授权、申请 XaaS 授权、授权记录、授权申请接口人入口。<br>2. 点击业务入口后切换主工作区内容并同步导航选中状态。<br>3. 移动端默认收起，用户点击菜单按钮后展开。 | V2 |

| 全局框架 | 响应式布局 | 1. 桌面端保留左侧导航和产品授权模块导航。<br>2. 紧凑桌面将左侧导航收为图标轨。<br>3. 移动端隐藏产品授权模块导航，表单改为单列并保留底部操作区。 | V2 |

| 申请产品授权 | 设备识别与授权场景 | 1. 根据设备来源、授权状态和授权历史识别可申请场景。<br>a. 首次开通测试授权。<br>b. 重新开通测试授权。<br>c. 调整当前测试授权。<br>2. 有效授权可申请延期、增开模块或扩大容量/规格。<br>3. 销售设备仅开放适用的商务类授权事项。<br>4. 展示来源、授权中台、累计测试、历史申请和最新授权有效期等识别结果。 | V2 |
| 申请产品授权 | 超期与特殊申请补充 | 1. 区分授权已过期与累计测试超期，两类状态可同时出现。<br>2. 超期申请提示升级审批及区域经营成本影响。<br>3. 超期申请要求填写申请理由，并支持上传证明材料。<br>4. 特殊规则、不可自助或设备不一致时阻断提交并说明原因。 | V2 |
| 申请产品授权 | 多设备兼容与拆单 | 1. 校验多设备的产品线、基础场景、申请事项、来源、借测单、材料和审批规则是否一致。<br>2. 同借测单设备允许自动补齐并由用户删除不参与本次申请的设备。<br>3. 多设备条件不兼容时明确指出冲突设备和原因，并要求拆分申请。 | V2 |
| 申请产品授权 | 授权配置 | 1. 以模块卡片展示当前产品线可配置的授权模块。<br>2. 已授权模块默认开启，并展示“已授权”状态及授权有效期。<br>3. 支持模块启用/停用、展开/折叠、全部展开/全部折叠。<br>4. 支持填写模块参数、容量和授权日期。<br>5. 支持将统一授权日期应用到所有已启用模块。<br>6. 已禁用模块不参与校验和提交。 | V2 |
| 申请产品授权 | 右侧模块导航 | 1. 桌面端展示当前产品线对应的模块列表。<br>2. 点击导航项定位到对应模块卡片。<br>3. 页面滚动时同步更新当前模块高亮状态。<br>4. 产品线切换时刷新导航内容。<br>5. 移动端始终隐藏，不遮挡表单。 | V2 |
| 申请产品授权 | 底部操作区 | 1. 实时提示当前提交前置条件，如识别设备、选择申请内容或补齐信息。<br>2. “重置”清空表单和派生状态，并恢复默认产品模式。<br>3. “立即获取”执行校验、组装设备事实和规则快照后提交申请。<br>4. 查询失败时支持重试或保存草稿。 | V2 |

| 申请 XaaS 授权 | 客户与行业 | 1. 搜索并选择客户。<br>2. 一级行业、二级行业级联选择。<br>3. 客户和行业信息作为 XaaS 申请的必填业务依据。 | V2 |

| 授权记录 | 页面标题与状态概览 | 1. 展示授权记录页面说明。<br>2. 按全部、待审批、审批中、已通过、已授权、已驳回、已过期汇总记录数量。<br>3. 点击状态项直接筛选列表，并与状态筛选条件同步。 | V2 |
| 授权记录 | 移动端快捷筛选 | 1. 提供设备 ID/SN 搜索。<br>2. 提供类型、状态、产品线快捷筛选。<br>3. 支持展开更多筛选条件和一键重置。 | V2 |
| 授权记录 | 查询条件 | 1. 按授权类型、审批状态、产品线、设备 ID/SN、申请人、申请日期筛选。<br>2. 支持查询和重置。<br>3. 查询条件与状态概览、移动端快捷筛选保持同步。 | V2 |
| 授权记录 | 授权记录列表 | 1. 展示申请编号、授权类型、申请平台、产品线/方案、版本、客户、授权对象、区域、有效期、申请人、申请时间、审批状态和操作。<br>2. 固定关键列和“审批状态/操作”列，横向滚动时保持可读。<br>3. 解决方案记录支持展开查看子设备授权明细。<br>4. 支持分页、每页条数切换和页码跳转。 | V2 |
| 授权记录 | 记录操作 | 1. 根据记录状态展示查看、审核、下载、复制、续期、重新提交、撤销等操作。<br>2. 复制产品授权或 XaaS 记录后跳转对应申请页并回填可复用信息。<br>3. 已授权、已过期记录允许下载本次生成的授权文件。<br>4. 已过期或需延期记录可发起续期申请。<br>5. 已驳回记录可补充信息后重新提交。 | V2 |
| 授权记录 | 详情侧边抽屉 | 1. 保留列表上下文，在右侧展示记录详情。<br>2. 产品授权详情依次展示申请信息、客户信息、产品授权明细、业务补充信息、开通结果和审批信息。<br>3. XaaS 详情依次展示申请信息、客户信息、订阅授权明细、业务补充信息、开通结果和审批信息。<br>4. 不同授权类型保持统一宽度、标题、只读表单和分区样式。 | V2 |
| 授权记录 | 审核申请侧边抽屉 | 1. 按详情页相同信息骨架向审批人展示申请依据。<br>2. 展示已有审批记录和当前审批节点。<br>3. 审批人必须主动选择通过或驳回，并填写审批意见。<br>4. 审批操作完成后更新当前记录状态；原型仅演示页面交互，不定义真实审批流。 | V2 |
| 授权记录 | 撤销与结果反馈 | 1. 撤销申请使用二次确认弹窗，并要求填写撤销原因。<br>2. 下载、复制、续期、重新提交和审核操作提供结果提示。<br>3. 操作入口支持悬浮说明和键盘访问。 | V2 |
| 授权记录 | 导出 | 1. 提供授权记录列表导出入口。<br>2. 导出内容受当前查询条件约束。 | V2 |

## 4. 范围说明

1. 本文档为需求概述，用于说明页面信息架构和功能边界，不替代字段级、规则级详细需求文档。
2. 当前原型中的审批规则计算用于演示申请分流和页面展示；真实审批流、授权开通和外部系统接口需由对应系统另行定义。
3. 后台首页、系统设置、操作手册、授权申请接口人目前主要作为页面入口或预留位置，不在本次 V2 核心业务功能范围内展开。
4. 页面中隐藏的旧版查询区、仅保留在代码中的遗留交互和异常处理演示不纳入本概述。
