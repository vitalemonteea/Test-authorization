│  │  ├─ 授权文件

└─ 设备行（每个设备一行）

   │  │  ├─ 申请平台

   │  │  ├─ 授权场景（首次开通）

   │  │  └─ 方案编码 / 方案名称
   │  ├─ 客户信息
   │  │  ├─ 客户名称
   │  │  ├─ 客户类型

   │  │  ├─ 设备id
   │  │  ├─ SN
   │  │  ├─ 来源

   │  │  └─ 借测单号 / 借测人 / 借测状态 / 借测类型
   │  ├─ 配置变更

   │  │  ├─ 授权模块
   │  │  ├─ 规格
   │  │  ├─ 集群标识

      │  ├─ 云授权ID
      │  ├─ 出版版本
      │  ├─ 开通时间
      │  ├─ 接收邮箱
      │  └─ 授权码
      └─ 审批信息
         └─ 整单审批结果
