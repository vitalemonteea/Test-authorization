## 1. 需求背景

### 1.1 业务现状
解决方案型测试授权通常由多个协同运作的产品线打包组成（如企业云一体化方案、分布式安全运营方案、全球加速及全球组网方案等）。当前业务中，因资产借测与测试授权系统割裂，业务人员需按单产品反复发起多次授权申请，流程繁琐且难以保证同一方案下各产品授权期限与客户环境的一致性。

同时，部分解决方案存在设备硬件产品线与 XaaS 云服务产品线混排的场景，不同产品线的授权对象和校验逻辑不同；新资产系统完成借测审批后，若缺乏统一关联机制，容易导致方案产品组合脱节、二次手工录入繁琐及授权结果无法原子交付的问题。

### 1.2 需求目标
在 W3 测试授权平台内完成解决方案配置维护、关联借测单发起、纯软件申请、多产品线工作台参数配置、整单审批与单一汇总授权记录展示。
系统支持一张申请单承接多个产品线（设备线与 XaaS 线并存），方案范围只读锁定，统一授权到期时间，全产品原子化开通与异常回滚；并响应业务方建议，实现业务申请信息与产品授权组合的灵活自由配置，避免方案推广时频繁进行代码开发。

| 系统 | 模块 | 需求概述 | 说明 |
| :--- | :--- | :--- | :--- |
| W3 | 解决方案配置中心 | 维护解决方案编码、名称、产品组合、授权天数及业务申请信息字段引擎 | 配置归属 W3，向新资产系统提供只读查询接口 |
| W3 | 申请基础信息与入口 | 提供关联借测单与纯软件本地申请两种入口，客户信息由 CRM 带入，必选所属行业 | 借测单需客户级联筛选，只允许关联审批通过借测单 |
| W3 | 方案范围只读锁定 | 展示方案编码、名称、关联产品线标签列表及统一授权时间 | 严格只读，杜绝申请人手工增删或替换产品线 |
| W3 | 业务申请信息 | 根据方案配置引擎动态自适应渲染专属业务评估信息（DSOC/加速/组网/MSS/DSP等） | 字段名、类型、多选项自由配置，调研基准直接对齐规则表 |

| **下游许可证中台 / 云图** | 接收 W3 下发的产品授权与云服务开通指令，返回具体授权码；提供失败时的批量作废撤销与回滚接口能力。不处理解决方案业务合规审批。 |

### 2.4 审批与处理口径

| 事项 | 口径 |
| :--- | :--- |
| 审批单粒度 | 整套解决方案作为一张申请单统一审批，不按产品线拆分审批单。 |
| 审批驳回机制 | 任一审批节点驳回时整单驳回，申请人可基于原单修改数据后重新提交。 |

| 成对协同组件守底口径 | 具有成对互补协同关系的组件（如 STA/AF、AF/aES），允许同时开启；关闭一个另一个必须自动开启，严禁同时关闭。 |

## 3. 业务流程

### 3.1 解决方案型授权申请与执行流程
1. W3 配置管理员在「系统设置」→「解决方案配置」维护方案编码、名称、产品线组合、统一授权天数（authDays）以及业务申请信息模板与自由配置字段；新资产系统通过只读接口获取启用的方案数据。
2. 业务人员在资产系统发起借测申请并独立完成资产审批；审批通过后，流程在资产系统结束，不向 W3 发送业务消息。
3. 业务人员主动登录 W3，进入「解决方案型授权」页面，选择“关联借测单”或“纯软件本地申请”。输入客户筛选合法借测单，系统自动带出 CRM 客户信息并在客户概要即时回显客户全局云图身份；申请人下拉选择所属行业（必选，对齐 XaaS 字典）。
4. W3 实时校验借测单准入状态：必须为“审批通过且未归还、未撤销”。校验通过后带出借测关键信息，并在「方案范围」锁定方案及产品线（只读不可改），按配置天数动态计算统一授权到期时间。
5. 若方案配置了业务申请信息字段，系统展开「业务申请信息」区块，前端引擎自适应渲染文本输入、单选、多选、文件上传等动态表单组件，用户补充主打场景、驱动力、预期效果、调研文档或竞对等评估信息。
6. 进入「授权参数」多产品线工作台，申请人按左侧导航逐个填写产品参数；未上线的按需产品线（如 SASE-SWG）默认关闭，不参与校验；成对协同组件（如 STA/AF、AF/aES）执行至少开启一个的守底联动；设备线配置版本、设备 ID 及模块卡片；XaaS 线配置云服务参数并校验客户全局云图身份；所有产品线授权到期日强制对齐统一到期时间。
7. 点击“提交 W3 整单审批”，前置校验全单必填项。校验通过后生成一张 W3 申请单进入审批流。审批人查看整单方案并作出通过或驳回结论。
8. 审批通过后执行全产品原子授权：预校验通过后并行下发，全部成功则在授权记录中生成一条以 SOL 开头的主记录，并可展开查看所有产品明细；任一产品失败则整单回滚作废已开通产品，整单标记为失败。

## 4. 解决方案型测试授权需求明细

### 4.1 解决方案配置管理

#### 1、初始状态
系统由管理员在配置中心统一维护解决方案与产品线清单的基线配置。初始状态下，系统展示已维护的解决方案定义列表，包含方案编码、方案名称、关联产品线集合、业务申请信息模板及字段项、统一授权天数及当前启用状态；列表默认按更新时间倒序排列。新资产系统通过接口同步读取处于“启用”状态的方案配置；若系统中未配置任何方案或方案全部处于停用状态，测试授权申请端不可发起解决方案型授权。

#### 2、交互逻辑说明
管理员可按方案编码或方案名称进行关键字检索，或按状态（全部/启用/停用）筛选方案；支持新增与编辑解决方案：
（1）基础信息录入：录入方案编码、方案名称、统一授权天数（大于0的正整数），并勾选其所包含的产品线范围（支持硬件设备产品线与 XaaS 云服务产品线混排）；
（2）业务申请信息自由配置引擎（业务核心诉求落地）：方案提供业务信息模板选择（包括标准通用无业务信息、分布式安全运营 DSOC、全球加速 ACCEL、全球组网 NETWORK、安全托管服务 MSS、数据安全方案 DSP 及自定义动态字段配置）；管理员可自由添加业务调研字段、修改字段名称、选择控件类型（单行文本、多行文本、单选下拉、多选复选框、附件上传、数字）；针对单选下拉与多选复选框控件，支持管理员自由录入和维护可选项列表（多个选项使用英文逗号分隔），并支持设置必填标记与删除字段；彻底实现业务调研信息免代码发版随配随用；
（3）启停状态与接口快照：支持对已有方案进行一键启用/停用切换，停用后新资产系统与测试授权申请端即时不可选；提供模拟接口读取功能，支持实时查看新资产系统调用的方案配置数据快照。

#### 3、字段校验规则
方案编码必填且全局唯一，不可包含特殊字符，新增后锁定只读不可修改；方案名称必填且系统内不可重名；统一授权天数必填，必须为大于 0 的正整数（用于后续申请时统一锁定全方案各产品线的授权周期）；关联产品线必选，至少勾选一条产品线；若配置了业务申请信息字段，字段名称不可为空；已产生历史测试授权单据的方案禁止物理删除，仅允许变更为停用状态。

#### 4、提交逻辑处理
方案新增、编辑或启停状态变更后即时持久化生效，自动记录管理员操作审计日志（操作人、时间、变更内容）；状态变动实时生效于测试授权申请端下拉选项及新资产系统同步接口；历史已审批完成的授权单据按申请时的历史快照生效，不受后续方案配置调整的影响。

#### 5、验收标准
方案列表展示准确，支持多维度检索与启停流转；方案编码与名称防重校验拦截生效；授权天数非正整数、产品线未勾选等异常前置阻断；业务申请信息字段引擎支持自由增删改查及选项配置；停用方案在申请端和资产系统中即时不可选；配置变更后不影响历史单据数据完整性。

| 字段 | 数据来源 | 可编辑 | 必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 方案编码 | 管理员新增录入 | 新增时可填，编辑时只读 | 是 | 系统全局唯一标识，如 SOL-CLOUD-001 |
| 方案名称 | 管理员录入 | 是 | 是 | 解决方案全称，如企业云一体化方案 |
| 关联产品线 | 勾选产品目录 | 是 | 是 | 至少选择一个产品线，支持设备线与 XaaS 线混排 |
| 业务申请信息 | 配置中心自由配置 | 是 | 按方案需要 | 选择预置业务模板或自定义动态字段（字段名、类型、多选项、必填项自由配置） |
| 授权时间 | 管理员录入天数 | 是 | 是 | 正整数天数，如 30、60、90，用于申请时计算统一到期日 |
| 状态 | 系统维护 | 操作列点击切换 | 是 | 启用 (enabled) / 停用 (disabled) |

### 4.2 解决方案授权申请

#### 4.2.1 申请入口与借测单关联

##### 1、初始状态
申请人进入测试授权申请页面，系统提供「关联借测单」与「纯软件本地申请」两种申请模式。初始状态下，系统默认处于「关联借测单」模式，页面处于待选定客户与待选择借测单状态，方案范围及各产品线参数暂不加载；若本次为纯软件方案试用或无需借用实体硬件设备，申请人可主动切换为「纯软件本地申请」模式。

##### 2、交互逻辑说明
（1）客户基础信息带入：申请人搜索并选定客户，系统自动从 CRM/主数据带出客户名称、销售负责人、客户类型（KA/普通）、客户一级与二级行业分类，并在客户概要中即时展示客户全局云图身份状态；  
（2）行业二级联动选择（1:1 完整移植 XaaS）：在客户信息区域配置「行业」级联选择组件（两级均必填），带「ⓘ」备注悬浮气泡（用户故事：选择客户所属行业分类，用于客户分层管理和行业化运营分析；交互规则：一级行业选择后，二级行业根据一级分类联动展示，提交时两级均必填）。一级行业字典包含：政府、金融、教育、医疗、互联网、制造业、能源、交通、运营商；二级行业由一级联动展示（如：政府联动中央部委/省市级政府/区县级政府/公检法等），选定客户时自动带入客户所属行业，申请人亦可自由调整联动选择；  
（3）准入强校验与借测单关联：在关联借测单模式下，系统实时拉取该客户名下在新资产系统中已审批的所有借测单数据。点击「查询并关联」，系统执行借测单准入强校验：仅“审批通过且未归还、未撤销”且未被占用的借测单允许准入。准入通过后带出借测关键信息（借测单号、申请人、客户、期限、产品数），并自动锁定加载方案范围。若借测单处于“审批中/未审批”、“已归还”、“已撤销”或“已被关联占用”，系统弹出明确阻断提示卡片，严禁进入后续环节；  
（4）方案范围固化锁定：方案包含的产品线清单及统一授权天数（authDays）严格只读锁定，杜绝申请人手工增删或替换产品线；系统依据 authDays 自动联动计算统一授权到期日（申请日 + authDays），并强制分发至方案下所有产品线，保持全方案授权周期严格一致。纯软件申请模式同样选择启用方案并锁定方案范围与到期日。

##### 3、字段校验规则
授权类型必选；关联借测单模式下客户与合法借测单必选；纯软件模式下方案与客户必选；行业一级与二级必须全部选定且符合联动关系；仅“审批通过且未归还、未撤销”借测单可通过准入校验；方案产品组合只读不可篡改；统一授权到期时间不可为空。

##### 4、提交逻辑处理
将申请来源标识（borrow / local）、客户基础信息快照、一级与二级行业分类（组合为'一级 / 二级'）、借测单全量元数据快照、锁定的方案编码、名称、产品线列表及统一到期日深拷贝存入单据模型中，随单提交。

##### 5、验收标准
两类入口切换顺畅且数据互斥隔离；行业二级联动及 Tooltip 备注与 XaaS 保持 1:1 一致，一级改变自动重置刷新二级，两级未选全均能精确阻断；未审批、已归还、已撤销借测单 100% 阻断拦截；合法借测单回填准确；方案范围与产品清单严格只读锁定；统一授权到期日准确联动至所有产品线。

#### 4.2.2 业务信息与产品线参数配置（重点规范 XaaS 与云图 ID 校验）

##### 1、初始状态
方案范围锁定后，系统根据方案配置中心维护的业务申请信息字段定义以及《安全方案测试申请规则.xlsx》，初始化「业务申请信息」与「多产品线参数工作台」两部分填报区域。业务信息部分根据方案绑定的字段模型动态呈现专属调研字段（初始处于待填报状态）；产品线工作台初始化该方案下所有产品线的参数填报面板，核心必选产品线默认处于待填报状态，按需/可选产品线默认处于未激活状态。针对 XaaS 云服务产品线（SASE-GA、SASE-SWG、SASE-ZTNA、SaaS-XDR、MSS 等），系统自动隐藏硬件设备字段，并根据已选客户检测并回显全局「云图 ID（tenantId）」；若客户尚未在云图中台开户，系统处于全局未入驻强阻断状态。

##### 2、交互逻辑说明
（1）业务申请信息自由配置引擎渲染：业务申请信息彻底解耦底层技术代码，根据方案配置中心维护的字段模型（支持单行/多行文本、单选下拉、多选复选框、附件上传、数字）自适应渲染；业务规则以《安全方案测试申请规则.xlsx》为基准动态驱动，推广新方案或微调调研字段完全免开发发版；  
（2）成对协同组件“至少选一个”互斥守底交互（重点规范）：针对具有成对协同属性的组件（如安全托管服务方案中的 STA 与 AF，或 AF 与 aES 等），系统在多产品线导航及开关层面提供互斥守底保障：允许两个组件同时开启；若用户点击关闭其中一个组件，系统检测到另一个组件若处于关闭状态，将自动触发另一个组件保持开启或自动将其开启，严禁两者同时处于关闭状态，防止因关键依赖组件全部关闭导致方案无法交付或服务失效；  
（3）硬件设备产品线参数填报：继承借测单回填的设备 ID 与设备 SN，申请人选定软件版本，并可按需开启或选配功能模块卡片（如 AC/AF 的安全订阅、HCI 的算力存储规格）；  
（4）客户全局云图身份与 XaaS 强校验规范（重点规范）：  
  - 全局身份定位于客户主体：云图 ID（tenantId）作为客户顶层全局租户身份，而非某个子产品的局部参数；选定客户后，系统在客户基本信息卡片中即时回显全局云图身份标签（如“云图ID: [tenantId]”或红色高亮“未关联云图账号”）；  
  - 包含 XaaS 全单坚决强阻断：方案若包含任一 XaaS 产品线，已选客户必须具备合法有效的云图 ID；若客户尚未在云图中台开户或缺失云图 ID，系统强行阻断整单提交，并明确提示引导先在云图中台完成客户租户建档入驻；  
  - 彻底屏蔽伪硬件信息：XaaS 产品界面 100% 隐藏“设备 ID”与“设备 SN”输入项，授权记录中设备 ID 统一映射为“云图ID: [tenantId]”，设备 SN 展示为破折号“—”；  
  - XaaS 专属规格录入：SASE-GA 带宽档位（5M/10M/15M/20M/30M/50M）、SASE-ZTNA 授权并发用户数（正整数）、SaaS-XDR/MSS 接入日志量与客户信息收集表等。

##### 3、字段校验规则
云图 ID 客户全局身份强校验（核心阻断项）：方案若包含任一 XaaS 产品线，已选客户必须拥有有效合法的云图 ID（tenantId）。无云图身份或云图状态异常时，全单坚决阻断提交，拦截率 100%；成对协同组件守底校验：成对协同组件严禁同时关闭；业务信息校验：严格对齐字段配置模型与《安全方案测试申请规则.xlsx》中标记为必填的调研字段，未补全阻断提交；硬件产品参数校验：版本必填，借测设备 ID/SN 必须有效，已启用模块参数符合合法范围；XaaS 规格参数校验：SASE-GA 带宽必选；SASE-ZTNA 用户数必须为大于等于 1 的正整数；SaaS-XDR/MSS 日志量与信息收集表必填。

##### 4、提交逻辑处理
组装包含业务信息快照与各激活产品线参数快照的数据包。针对 XaaS 产品线，提交数据中的 deviceId 统一固化为“云图ID: [tenantId]”，deviceSn 统一写入破折号“—”；未激活的按需产品线彻底从提交快照中剔除，不生成下游授权任务。

##### 5、验收标准
业务信息准确按自由配置字段模型动态展开；硬件产品线与 XaaS 产品线字段清晰隔离，XaaS 界面 100% 隐藏设备 ID 与 SN；客户全局云图身份标签展示准确；无云图账号客户申请包含 XaaS 的方案时，前置告警与提交拦截 100% 触发；成对协同组件“至少选一个”互斥守底联动生效；具备有效云图 ID 的客户能顺畅填写规格参数并通过校验；按需产品线开关开启/关闭逻辑与数据过滤完全正确。

| 字段/对象 | 适用产品 | 数据来源 | 必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 云图ID (tenantId) | 所有 XaaS 产品线 (SASE/XDR/MSS等) | 云图中台客户全局租户身份绑定 | 是 (核心阻断项) | 客户全局顶级身份与 XaaS 授权唯一核心标识；客户无云图账号或无云图ID时系统强行阻断提交并引导建档入驻 |
| 带宽档位 | SASE-GA | 下拉选项 | 是 | 档位可选 5M / 10M / 15M / 20M / 30M / 50M，满足各加速测试场景 |
| 授权用户数 | SASE-ZTNA / aTrust | 数字输入框 | 是 | 并发接入用户数，必须为正整数（如 50、100） |
| 日志量 / 收集表 | SaaS-XDR / MSS | 文本输入 / Excel文件上传 | 是 | 单位为万条/天，客户现场信息收集表必传 (.xlsx/.xls) |
| 是否 PK / 友商名 | SaaS-XDR / XDR | 下拉选项 / 文本输入 | 是 | 选择存在竞对 PK 时动态展开友商名称录入框，必填 |

#### 4.2.3 解决方案整单审批与原子交付回滚

##### 1、初始状态
申请单在所有已激活产品线参数校验通过前处于编辑草稿状态，审批流程未发起。系统处于整单校验前置监听状态。

##### 2、交互逻辑说明
点击提交按钮，顺序执行严格前置校验（单据与客户有效性、所属行业必填性、业务信息完整性、XaaS 全局云图身份有效性、成对协同组件守底规则、所有激活产品线必填参数与模块卡片完整性）。任一不符在页面高亮报错并阻断。  
校验通过后生成统一的 W3 方案申请单号（SOL-...）进入待审批状态。整单走统一审批流，任一审批节点驳回则整单驳回，申请人可修改重提。  
审批通过后触发下游授权原子下发：系统调用各产品线发号中台与云图中台开通授权。若所有产品均成功，整单标记为“已授权”并归档；若任一产品线开通失败，立即触发整单事务回滚机制，自动调用作废接口撤销已开通产品的 License，整单标记为“开通失败”，杜绝方案残缺交付。

##### 3、字段校验规则
前置校验覆盖全单所有激活产品线，不允许存在任何空缺必填项；终审执行前再次对齐借测单状态。

##### 4、提交逻辑处理
生成包含全套参数深复制快照的申请单据，维系统一全局事务 ID 用于回滚追踪。

##### 5、验收标准
任意漏填必填项点击提交均能精准定位提示；提交后单据状态流转正确；失败整单回滚机制彻底杜绝残缺授权。

#### 4、提交逻辑处理
数据层以一对多主子表架构存储，主行承载整单状态与统计指标，子表承载各产品 License 明细，随整单原子授权成功后一次性写入并绑定主行编号。

#### 5、验收标准
解决方案展示为单条主行；主行指标统计准确；搜索与类型筛选联动精确；展开子表格排版整齐无错位；设备与 XaaS 产品线字段区分展示准确；所有产品授权码完整呈现。

## 5. 外部协同与接口需求明细

### 5.1 新资产系统协同
- **5.1.1 W3 解决方案配置查询接口**：新资产系统通过该接口获取 W3 处于启用状态的解决方案编码、名称、产品线类型列表（区分 device/xaas）及授权天数（authDays）。新资产系统仅在用户建借测单时读取，不嵌入 W3 配置页。
- **5.1.2 借测单状态与快照查询接口**：W3 申请人在关联借测单时调用新资产系统，获取借测单号、审批状态、客户、借测人、借测起止日、归还状态、撤销状态及已审批方案范围快照；若含 XaaS 线同步返回客户绑定的全局云图账号与云图ID。

### 5.2 下游许可证平台与云图中台协同
- **5.2.1 批量授权下发接口**：整单审批通过后，W3 向下游中台派发批量开通任务，按各产品线参数生成 License 文件或激活云端租户实例。
- **5.2.2 异常原子回滚接口**：两阶段事务保障。任一产品开通失败，W3 立即调用中台作废接口撤销已开通的产品凭证，确保整套方案交付结果的一致性。

## 7. 业务方需求落地：业务申请信息与产品组合灵活配置规范

### 7.1 架构设计背景与免代码开发原则
业务方明确要求：“页面的业务申请信息、产品授权组合要考虑灵活配置。后续随方案推广，需要收集的信息和方案产品组合可能会有变化，不要每次调整都要开发”。  
针对该核心诉求，系统在架构上确立免代码开发扩展原则：底层实现方案元数据驱动模型（Metadata-Driven Model），将产品授权组合与业务调研表单与前端静态页面彻底解耦。推广新方案或微调调研字段时，无需进行全链路代码重新发版。

### 7.2 产品组合元数据驱动方案
方案与产品线的组合关系完全由 W3「解决方案配置」数据表驱动。管理员在抽屉中自由勾选产品目录并配置授权天数后，申请端根据接口返回的产品线动态构建左侧工作台导航，复用各产品的标准参数组件，产品组合调整 0 代码发版。

### 7.3 业务申请信息自由配置字段引擎
业务申请信息采用自由配置字段引擎（Field Engine）。管理员在配置方案时，既可选择标准预置模板，也可自定义扩展动态字段：
1. **字段名称自由定义**：管理员可按业务调研诉求自由命名字段（如“测试主打场景”、“PK友商”、“能否远程”、“客户交流纪要”等）；
2. **控件类型丰富支持**：支持单行文本（text）、多行文本（textarea）、单选下拉（select）、多选复选框（checkbox）、附件上传（file）及数字输入（number）；
3. **选项列表自由增删改**：对于单选下拉与多选复选框，管理员在配置界面录入以逗号隔开的候选值，引擎自适应解析为候选选项；
4. **必填与删除控制**：每个字段均可独立勾选“必填”属性，未补全时整单提交自动触发前置拦截校验；字段支持行级实时删除；
5. **前端自适应渲染**：申请端根据方案绑定的字段 Schema 动态生成表单与校验规则，业务规则直接以《安全方案测试申请规则.xlsx》为基准动态驱动，业务调研表单调整彻底告别代码开发。

| 模板标识 | 适用方案 | 核心字段与组件 | 扩展方式 |
| :--- | :--- | :--- | :--- |
| NONE | 通用解决方案（如企业云） | 无特殊业务信息，直接进入工作台 | 标准开箱即用，无需配置 |
| DSOC_TEMPLATE | 分布式安全运营方案 | 主打场景、驱动力、预期效果、调研文档上传、转销计划 | 支持在配置界面自由增减多选选项及附件项 |
| ACCEL_TEMPLATE | 全球加速方案（SaaS/本地版） | 客户需求、项目规模、竞争对手、所在省份、备注 | 支持配置字段条件显隐，满足不同子方案诉求 |
| NETWORK_TEMPLATE | 全球组网方案 | 客户需求、项目规模、竞争对手（收起省份/备注） | 复用加速模板核心字段，自动屏蔽地域属性 |
| MSS_TEMPLATE | 安全托管服务方案 | 所属行业、客户联系人、客户组件情况、本次测试PK范围 | 支持在配置界面按现场调研诉求自由增减字段 |
| DSP_TEMPLATE | 数据安全方案 | 关注价值、风险场景、PK友商、能否远程、预算、交流纪要 | 包含多选、下拉与附件复合字段，自适应渲染 |
| CUSTOM_TEMPLATE | 未来推广新方案 | 按业务调研诉求自由组合文本、下拉、复选与文件控件 | 直接在抽屉中自由新增字段，自适应校验与审批 |

### 7.4 客户全局云图身份与成对协同组件守底规范
1. **客户全局云图身份规范**：云图 ID（tenantId）作为客户顶层全局租户身份，由系统自动绑定并在客户信息区回显；方案包含任一 XaaS 产品线时，无云图 ID 全单强行阻断提交；
2. **客户所属行业规范**：客户基本信息区域必选「所属行业」，行业字典与平台 XaaS 字典保持严格 1:1 对齐；
3. **成对协同组件守底规范**：针对方案中具有成对互补关系的协同组件（如 STA 与 AF，或 AF 与 aES），交互上支持两者同时开启；若关闭其中一个，另一个必须自动开启，严禁两者同时处于关闭状态，防止关键交付组件脱节。
