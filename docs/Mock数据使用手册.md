> 更新时间：2026-07-27
> 适用页面：`测试设备授权平台V2.html`  
> 默认客户：`C100001 / 深圳市腾讯计算机系统有限公司`。

**使用前先看“复现客户”列。** 授权历史会按规则中的客户口径重新查询；同一个设备可以被不同客户、不同批次重复使用，因此搭配不同客户时结果可能不同。表中的客户只用于稳定复现指定历史场景，不代表设备固定归属于该客户。

## 8. 续期识别 Mock

续期识别属于页面遗留交互，当前设备驱动主流程通常不会展示该区域。需要单独验证时使用以下规则：

- `.info` 文件名或网关 ID 包含 `over`、`expired`、`超规`、`超期`，识别为“超规续期”。
- 其他合法 `.info` 文件名或非空网关 ID，识别为“常规续期”。
- 超规续期模拟历史到期日为当前日期前 18 天；常规续期为当前日期后 15 天。
- `.info` 文件仅接受 `.info` 后缀。

示例：

| 输入 | 预期 |
| --- | --- |
| `gateway-normal-001` | 常规续期 |
| `gateway-over-001` | 超规续期 |
| `device-expired.info` | 超规续期 |
| `device-normal.info` | 常规续期 |

## 12. 使用注意事项

1. 严格按照“常用演示组合”中的客户列操作；需要历史记录的既定场景使用 `C100001`。
2. HCI/SCP 以文件名决定 Mock 变体，不会真正解析文件内容。
3. 硬件借测会严格校验设备事实；借测单中存在但设备事实库未登记的设备仍会被阻断。
4. 纯软测试允许任意 ID/SN，只查询授权历史，不校验客户设备资产有效性。
5. 首次开通、重新开通和有效期内调整是基础场景；“销售设备”“累计超期”是并行标签，不是额外场景。
6. 多设备基础场景、超期等级、来源或借测单不一致时，系统会提示拆单。
7. 设备不绑定固定客户；同一设备切换客户后应按新客户的历史重新识别场景。
