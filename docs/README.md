## 2. 状态定义

| 状态 | 含义 | AI 能否作为断言依据 |
| --- | --- | --- |
| **现行** | 当前有效，同一主题只有一个权威 | ✅ 可以 |
| **参考** | 背景/接口/方法论，不直接约束实现 | ⚠️ 需交叉确认 |

## 4. 维护规则

1. **移动/改名/状态变化**：同一次提交更新本表；否则视为迁移未完成。
2. **新增需求**：先在 `01-需求/` 领 REQ 编号，再建文件夹；一个需求一个文件夹。
3. **版本只写文档头**：`文档版本 / 更新时间 / 状态 / 适用范围` 四行；文件名不带“终稿/最终/最新”。
4. **md 是源，docx 是导出**：只改 md，用脚本生成 docx；禁止 Word 手改后不回填。
5. **xlsx 是数据源，脑图/导图是视图**：字段级冲突以 xlsx 为准。
6. **被替代 → 先登记替代关系，再移入 `99-归档/`**；归档只读，AI 默认不读。
7. **一次性产物 → `工作区/`**（gitignore，可整目录删），不要放 `docs/`。
