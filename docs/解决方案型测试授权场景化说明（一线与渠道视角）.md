# 解决方案型测试授权场景化说明（一线与渠道视角）

> 配套文档：《解决方案型测试授权申请概要方案》  
> 本文面向一线同事（销售、售前 SE、测试工程师）与渠道伙伴，用业务场景语言说明"该去哪儿申请、每一步做什么、最后拿到什么"。流程规则与概要方案一致，不涉及系统实现细节。

## 1. 一句话理解这个功能

以前给客户搭一套解决方案的测试环境，方案里有几个产品就要申请几次测试授权，一个一个填、一个一个等。现在只需要**选好解决方案、提交一次申请**，审批通过后系统自动把方案里所有产品的测试授权一次性生成，你在授权列表里只会看到**一条记录**，点开就能看到每个产品的授权信息。

## 2. 我该去哪儿申请（入口速查）

| 你的情况 | 去哪儿申请 | 审批在哪儿 | 授权结果在哪儿看 |
|----------|-----------|-----------|----------------|
| 方案里**含硬件设备**（要借测试机） | 新资产系统，创建借测单 | 新资产系统原有审批流 | W3 测试授权平台 |
| 方案是**纯软件**（不涉及硬件借用） | W3 测试授权平台 | W3 内独立审批 | W3 测试授权平台 |

记住一个原则：**要借硬件就走借测单，纯软件直接在 W3 申请**。不管从哪儿申请，最后都在 W3 看到同样的一条解决方案授权记录。

## 3. 场景一：给客户搭一套含硬件的解决方案测试环境

**场景**：办事处 SE 小张要给某医院客户做一套"云桌面解决方案"POC，方案里有超融合一体机（硬件）和配套管理软件，需要借测试机并开通全套软件测试授权。

**操作步骤**：

1. 在新资产系统创建借测单，业务场景选择对应的解决方案型场景。
2. 选择具体解决方案，系统自动带出方案名称和该方案需要填写的授权信息。
3. 填写客户、授权有效期等信息后提交。**注意：一个借测单只能选一个解决方案**，需要第二套方案就再建一个借测单。
4. 等待借测单审批。审批被驳回时，回到原单修改后重新提交即可，已填内容会保留。
5. 审批通过后**不需要再做任何操作**，系统会自动生成整套授权。

**你会看到的结果**：

- W3 授权记录列表里出现一条带"解决方案"标识的记录（编号 SOL- 开头）。
- 点开这条记录，方案里每个产品的授权明细一目了然：产品线、版本、设备信息、有效期、授权码。
- 拿着各产品的授权码去部署环境即可。

**注意事项**：

- 方案里包含哪些产品、什么版本，都是方案定好的，**申请时不能增删产品、不能换版本**。如果客户只需要其中一两个产品，请走原有的单产品测试授权申请。
- 授权是"整套一起生效"：只有方案里全部产品都成功，这条记录才显示"已授权"。

## 4. 场景二：纯软件解决方案，直接在 W3 申请

**场景**：渠道伙伴对接人小李要给客户演示一套纯软件安全方案（不涉及硬件借用），希望尽快拿到全套软件的测试授权。

**操作步骤**：

1. 在 W3 测试授权平台进入解决方案型申请入口（入口按场景和权限开放，看不到入口请联系区域接口人）。
2. 选择解决方案，系统自动加载方案内的产品和需要填写的内容。
3. 补充客户、设备、授权有效期等信息后提交。不需要填借测号，系统会生成独立的申请编号。
4. 申请进入 W3 内部审批。被驳回时可以修改后重新提交。
5. 审批通过后系统自动生成整套授权。

**你会看到的结果**：

- 和场景一完全一样的一条解决方案授权记录，点开可见全部产品的授权码。
- 全程在 W3 内完成，**不需要去新资产系统建借测单**。

## 5. 场景三：查看和使用授权

**场景**：授权批下来了，实施同事要逐个产品部署。

**怎么看**：

1. 在 W3 授权记录列表按借测号、方案名称、客户或产品线搜索，找到那条"解决方案"记录。
2. 点击展开，每一行就是方案里的一个产品：产品线、版本号、设备 ID、设备 SN、区域、授权有效期、授权码。
3. 按产品明细逐个取授权码部署。整条记录状态为"已授权"，说明全套产品都可以正常使用。

**提醒**：产品明细只是这条记录的组成部分，列表里不会出现单独的产品记录，别担心"少了记录"。

## 6. 场景四：客户要延长测试时间

**场景**：POC 周期比预期长，客户希望整套环境再延一个月。

**怎么办**：

| 方案类型 | 操作方式 | 结果 |
|----------|---------|------|
| 含硬件方案 | 在新资产系统对借测单办理延期，授权跟着硬件一起延 | 方案内**全部产品**的授权有效期同步延长 |
| 纯软件方案 | 直接在 W3 对这条授权记录操作延期 | 同上，整套一起延 |

延期后的生效方式按申请时选择的规则执行。延期是整套生效的——不能只给方案里某一个产品单独延期。

## 7. 场景五：测试结束了

- **含硬件方案**：测试机寄回仓库，货到仓库借测就结束了，**不需要额外审批**，整套授权同步结束。
- **纯软件方案**：授权到有效期自动结束，无需任何归还操作。

## 8. 场景六：授权出问题了怎么办

解决方案授权的原则是**要么整套成功、要么整套失败**，不会出现"一半产品能用、一半不能用"的情况。

- 如果记录显示"失败"：点开详情可以看到是哪个产品、哪一步出了问题。此时整套授权都不可用，已生成的部分也会被系统收回，**不要拿失败单里的授权码去部署**。
- 处理方式：后台会自动重试；仍失败的会转人工处理。如果着急，联系平台支持并提供申请编号即可。
- 审批驳回不算失败：驳回单改一改重新提交就行。

## 9. 场景七：客户又要测一轮（复制申请 / 一键续期）

- **纯软件方案**：支持对整条解决方案记录**复制申请**和**一键续期**，一键带出上次的填写内容，整套执行，不能只选其中几个产品。
- **含硬件方案**：请回到新资产系统重新创建借测单申请。

## 10. 常见问题

| 问题 | 答复 |
|------|------|
| 能只申请方案里的某几个产品吗？ | 不能，解决方案是整套申请、整套生效。只需要个别产品请走单产品测试授权 |
| 能调整方案里的产品或版本吗？ | 不能，方案内容由方案定义决定，申请时只读 |
| 一个借测单能挂两个方案吗？ | 不能，一单一方案；多套方案就建多个借测单 |
| 审批通过了会不会生成两条重复记录？ | 不会，同一次申请只会生成一条解决方案授权记录 |
| 想中途撤销授权怎么办？ | 没有单独的撤销操作：含硬件方案归还测试机即结束，纯软件方案到期自动结束 |
| 在哪儿能看到申请进度？ | 新资产系统来源看借测单审批状态；W3 来源在 W3 看申请单状态；授权结果统一在 W3 授权记录列表 |

## 11. 责任分工速览

| 角色 | 负责什么 |
|------|----------|
| 一线 / 渠道对接人 | 选对入口发起申请、如实填写客户和有效期信息、跟进审批、驳回后及时修改重提 |
| 新资产系统 | 借测单、解决方案定义、含硬件方案的审批、延期和归还的发起 |
| W3 测试授权平台 | 纯软件方案的申请与审批、整套授权的生成与展示、失败处理与人工支持 |
