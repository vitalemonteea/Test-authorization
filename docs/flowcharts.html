授权文件上传中间页 · 流程图

1. 原流程（旧旅程）

flowchart TD
  A["申请人建单
手填产品线/版本/客户/订单号/设备ID/SN"] --> B["提交审批"]
  B --> C{"审批结果"}
  C -->|"驳回"| C1["申请人修改后重提"] --> B
  C -->|"通过"| D["生成云授权序列号 + 云图链接"]
  D --> E["申请人线下把云图链接发给客户
邮件 / 企微 / 口头"]
  E --> F["客户打开云图授权中间页"]
  F --> G["客户上传 info 文件"]
  G --> H["平台生成授权文件"]
  H --> I["客户下载并导入设备激活"]
  E -.->|"客户不响应 / 不会操作"| J["申请人线下催"]
  J --> F
  J -.->|"客户把文件直接发给申请人"| K["原流程无申请人代传入口"]

3. Demo 中间页流程（当前实现）

flowchart TD
  A["申请人选择客户 + 产品"] --> B{"获取设备 info 的方式"}
  B -->|"路径 A：邀请客户上传"| C["生成 token + 表单快照
7 天有效期"]
  C --> D["申请人手动复制链接"]
  D --> E["客户打开 info-upload.html#token"]
  E --> F["客户选择 / 拖拽多个 .info"]
  F --> G{"逐文件校验
后缀/非空/≤2MB/产品线一致"}
  G -->|"失败"| H["页面显示错误
移除后重新选择"]
  H --> F
  G -->|"通过"| I["展示文件名 / SN / 集群标识"]
  I --> J["客户确认提交"]
  J --> K["任务 received
上传入口关闭"]
  K --> L["客户进度页
可催一下进度"]
  B -->|"路径 B：申请人手工上传"| M["申请人线下拿到文件"]
  M --> N["在表单中手工上传"]
  N --> O["逐文件生成设备事实"]
  K --> P["申请人「待补充申请」列表"]
  O --> P
  P --> Q["关联文件并恢复快照"]
  Q --> R["申请人提交申请"]
  R --> S["任务 completed"]
  S --> T{"授权生成"}
  T -->|"成功"| U["任务 authorized
客户同一链接下载 30 天"]
  T -->|"失败"| V["授权失败（当前未实现）"]

4. 目标流程（定稿）

flowchart TD
  A["申请人填写申请
除设备 info 外校验通过"] --> B["点击「发送上传链接」"]
  B --> C["弹窗：填写客户邮箱
选择触发方式 A / B"]
  C --> D{"邮箱格式有效?"}
  D -->|"否"| D1["提示输入正确邮箱"] --> C
  D -->|"是"| E["生成 token + 表单快照
平台邮件发送上传链接
7 天有效"]
  E --> F["申请进入「待设备信息」
出现在「我的待办」"]
  F --> G{"获取文件方式"}
  G -->|"客户点邮件链接上传"| H["客户打开免登录页"]
  G -->|"申请人线下拿到文件"| I["申请人手工上传"]
  G -->|"已有授权记录"| J["复用 info 与设备事实"]
  H --> K["客户逐文件校验并提交"]
  K --> L{"文件校验"}
  L -->|"失败"| L1["页面显示原因
客户重新选择"] --> K
  L -->|"通过"| M{"申请人选择的触发方式"}
  I --> M
  M -->|"A 直接发起"| N["系统自动提交申请"]
  M -->|"B 由我确认"| O["待确认
通知申请人"]
  O --> P["申请人查看设备事实并提交"] --> N
  J --> Q["直接开启 / 提交"]
  N --> R["进入审批
铃铛「待我审批」"]
  Q --> R
  R --> S{"审批结果"}
  S -->|"驳回"| S1["通知申请人
文件保留可复用"] --> T["修改后重提"]
  S -->|"通过"| U["授权文件人工上传
已有记录则复用"]
  U --> V["邮件发送授权文件
客户同一链接可下载 30 天"]
  V --> W["申请人收到完成通知"]
